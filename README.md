# Mnagavere
A lightweight, self-hosted manga reader and library built with HTML, CSS, vanilla JavaScript, and a Node.js backend. The site offers browsing and exploration, chapter and reader views, and account management so you can organize and read your manga collection directly in the browser. It supports archive formats (like CBZ) and is designed for easy local deployment.
